# 시스템 설계 - Sky Survivor (Web)

## 1. 개요
* **프로젝트명**: Sky Survivor (스카이 서바이버)
* **목표**: 모바일 웹 브라우저에서 60FPS를 유지하는 고성능 하이퍼 캐주얼 게임 개발

## 2. 기술 스택 (Technology Stack)
| 구분 | 기술 / 도구 | 선정 이유 |
|:--- |:--- |:--- |
| **Framework** | React 18 (Vite) | 선언적 UI 관리 및 빠른 개발 사이클 |
| **Rendering** | HTML5 Canvas | 고성능 2D 그래픽 렌더링 |
| **Styling** | TailwindCSS | 모바일 반응형 및 Glassmorphism UI |
| **Language** | TypeScript | 정적 타입을 통한 로직 안정성 확보 |
| **Concurrency** | Web Workers | 물리 연산 분리를 통한 UI 프리징 방지 (선택 사항) |

## 3. 시스템 아키텍처 (Architecture)
### 3.1. Game Loop (RequestAnimationFrame)
* 메인 루프에서 `update()`와 `draw()`를 분리하여 프레임 드랍 방지.
* `deltaTime`을 계산하여 모든 기기에서 동일한 속도로 게임이 진행되도록 설계.

### 3.2. Object Pool
* **Red Eagles**: 최대 20마리의 객체를 소환/해제 대신 활성/비활성 방식으로 관리하여 메모리 최적화.

## 4. 폴더 구조 (Directory Structure)
```
/
├── public/           # 이미지, 사운드 리소스
├── src/
│   ├── components/   # UI 컴포넌트 (Score, Overlays)
│   ├── engine/       # 게임 핵심 로직 (Physics, Collider)
│   ├── hooks/        # 입력 및 타이머 관리
│   ├── store/        # 점수 및 상태 관리 (Zustand)
│   └── App.tsx       # 진입점
```
