# ProjectGame (가제)

## 1. 프로젝트 개요
> **"재미와 몰입감을 주는 게임 개발"**
> 본 프로젝트는 사용자의 요구사항을 바탕으로 기획부터 배포까지 진행되는 게임 개발 프로젝트입니다.

## 3. 개발 규칙 (Rules)
1. **설계 우선 (Design First)**: 코딩 전 설계서 작성을 원칙으로 합니다.
2. **동기화 (Synchronization)**: 코드와 문서는 항상 일치해야 합니다.
3. **품질 타협 없음**: 최적화와 안정성을 최우선으로 합니다.
