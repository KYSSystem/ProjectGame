# API 및 인터페이스 설계

## 1. 네트워크 프로토콜 (Network Protocol)
> 멀티플레이 또는 서버 연동 시 사용

### 1.1. Packet Structure (Header + Body)
| Offset | Type | Field | Description |
|:--- |:--- |:--- |:--- |
| 0 | Short | PacketID | 패킷 종류 식별 |
| 2 | Short | Size | 전체 패킷 크기 |
| 4 | Bytes | Payload | 실제 데이터 (Protobuf/JSON) |

## 2. 입력 인터페이스 (Input Mapping)
### 2.1. Key Bindings
* **Move**: WASD / Arrow Keys
* **Action**: Space (Jump), Mouse Left (Attack)
* **Menu**: ESC
