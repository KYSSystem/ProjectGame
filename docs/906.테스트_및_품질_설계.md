# 테스트 및 품질 설계 - Sky Survivor

## 1. 통합 시나리오 (User Journey)

### Scenario 1: 웹 플레이 (Core Flow - Mobile & PC)
* **Step 1:** 접속 -> [Result] 'Sky Survivor' 타이틀과 함께 움직이는 배경 출력.
* **Step 2:** 화면 터치 또는 **Space/ArrowUp 키 입력** -> [Result] 피요가 위로 점프하며 게임 시작.
* **Step 3:** 점수 획득 -> [Result] 독수리를 피할 때마다 점수(m) 실시간 카운트.
* **Step 4:** 충돌 -> [Result] 화면이 흔들리며 게임 오버 팝업 출력.
* **Step 5:** 재시작 -> [Result] **마우스 클릭, Space 또는 Enter 키** 입력 시 즉시 다시 시작.

## 2. 품질 기준 (QA Standards)
* **Frame Rate**: 브라우저 기준 최소 55 FPS 이상 유지 (PC/Mobile 공통).
* **Input Latency**: 터치 및 **키보드 입력** 즉시 캐릭터 반응 (지연 시간 50ms 미만).
* **Responsive**: 다양한 해상도 및 화면 비율(PC 가로형, 모바일 세로형)에 자동 대응.
