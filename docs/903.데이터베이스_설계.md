## 2. ERD (Entity Relationship Diagram)
> 로컬 저장소(파일 기반)를 사용할 경우, 아래 구조는 JSON 객체 구조로 매핑됩니다.

### 2.1. PlayerData (플레이어 정보)
| 필드명 | 타입 | 설명 | Key |
|:--- |:--- |:--- |:--- |
| `player_id` | UUID | 교유 식별자 | PK |
| `nickname` | String | 사용자 닉네임 | - |
| `level` | Int | 현재 레벨 | - |
| `exp` | Long | 현재 경험치 | - |
| `gold` | Long | 보유 재화 | - |
| `created_at` | DateTime | 생성 일시 | - |

### 2.2. ItemInventory (아이템)
| 필드명 | 타입 | 설명 | Key |
|:--- |:--- |:--- |:--- |
| `item_uid` | UUID | 아이템 고유 ID | PK |
| `owner_id` | UUID | 소유자 ID | FK |
| `item_code` | String | 아이템 종류 코드 | - |
| `count` | Int | 보유 수량 | - |
