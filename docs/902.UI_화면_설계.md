# UI/UX 화면 설계 - Sky Survivor

## 1. 디자인 시스템
* **컨셉**: 저사양 모바일에서도 선명하게 보이는 **'Vibrant Flat Design'**.
* **폰트**: 고성능 게임 느낌의 **'Outfit'** 또는 **'Inter'**.

## 2. 화면 명세
### 2.1. 타이틀 (Title Scene)
* 상단 피요(Piyo) 캐릭터가 위아래로 둥둥 떠 있는 애니메이션.
* 중앙 [START] 버튼: 터치 또는 **Space 키** 입력 시 게임 시작.

### 2.2. 인게임 (Main Scene)
* **HUD**: 상단 중앙 점수표.
* **Canvas**: 배경 스크롤링, 피요, 독수리 렌더링 영역.
* **Input**: 화면 전체가 터치 영역 (클릭/터치 또는 **Space/ArrowUp 키** 입력 시 솟구침).

### 2.3. 결과 (Game Over Popup)
* **Glassmorphism**: 배경을 블러 처리한 뒤 반투명 팝업 출력.
* **Best Score**: 로컬 스토리지에서 기록을 불러와 비교 표시.

## 3. 연출 (VFX)
* **Feather Particle**: 충돌 시 깃털이 사방으로 흩어지는 효과.
* **Screen Shake**: 게임 오버 시 0.2초간 화면 진동.
