# 배포 및 인프라 설계

## 1. 빌드 파이프라인 (Build Pipeline)
### 1.1. Local Build
* **Debug Build**: 로그 활성화, 치트 허용
* **Release Build**: 난독화 적용, 디버그 심볼 제거, 최적화

## 2. 배포 환경 (Deployment)
* **Target Platforms**: Web Browser, **Android (PWA)**, iOS (PWA)
* **Installation**: Progressive Web App (PWA) 기술을 통해 홈 화면에 추가 및 독립 실행 가능
* **Store**: Web hosting (Vercel, GitHub Pages 등)

## 3. CI/CD (Continuous Integration)
* Github Actions 활용 (Push 시 자동 테스트 및 빌드)
