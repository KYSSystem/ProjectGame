# 공통모듈 설계

## 1. Utils (유틸리티)
* **MathUtils**: 벡터 연산, 거리 계산, 랜덤 확률 유틸
* **TimeUtils**: 타이머, 쿨타임 관리, 타임 스케일 제어
* **LogUtils**: 디버그 로그 래퍼 (레벨별 필터링)

## 2. Managers (싱글톤)
* **ResourceManager**: 프리팹, 텍스처, 오디오 동적 로드/언로드 (메모리 관리)
* **EventManager**: 옵저버 패턴 기반 이벤트 발행/구독 시스템

## 3. Constants (상수 정의)
* `MAX_HP`: 100
* `MOVE_SPEED_DEFAULT`: 5.0f
